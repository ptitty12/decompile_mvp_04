## fn_80249D44 (game/tu_80246D04) 99.25% -> MATCH

- Diff: retail `cmpwi r0,6; bgtlr; cmpwi r0,1; bltlr`, ours `cmpwi r0,6; bgtlr; cmpwi r0,0; blelr`.
- Cause: fold-const rewrites `s >= 1` to `s > 0` (and `s < 1` to `s <= 0`) for any positive INTEGER_CST, so no
  if-form can produce `cmpwi 1; blt`. A switch range node does: stmt.c emit_case_nodes for a leaf range compares
  `index > high` then `index < low` with the literal bounds (no fold).
- Fix: `int r = 0; switch (v->mB0C) { case 1: case 2: case 3: case 4: case 5: case 6: r = 1; break; } return r;`
  (group_case_nodes merges consecutive cases into one range; 2 nodes < CASE_VALUES_THRESHOLD so no table).
- GENERAL: a `cmpwi N; blt` / `cmpwi N; bgt` pair against literal bounds that an `if` would fold to `N-1`/`N+1`
  is a switch with a case range (consecutive cases to the same body).

  and the four call sites (fn_8024820C still matches). The definition (fn_8024796C, 0% in this unit) must use that order.
- GENERAL: a float parameter's position in the callee prototype shifts the live lengths of the caller's int
  parameters by one, enough to flip a callee-saved pair that differs by one priority step. When two int params are
  swapped and refs are equal, check every callee prototype's float position before touching the body.
