MVP Baseball 2005 browser engine, development build

Pick your own disc image of MVP Baseball 2005 for GameCube (USA, GV4E69). The page reads it on this computer and translates the game here; the image is never uploaded, and this server holds no game data. 


    

    

      Controls
      
Keyboard: Enter = START, X = A, Z = B, C = X, V = Y, arrows = D-pad, I/J/K/L = stick, Q = L, E = R,
        Space = Z. A gamepad works too (standard mapping).
